🚀 Panduan Lengkap: Dev & Aplikasi Multi-AI

🧠 1. Pusat Multi-AI (Chatbot)

Aplikasi ini bukan sekadar chatbot biasa — ini adalah hub multi-AI yang memungkinkan kamu berganti "otak" AI sesuai kebutuhan. Cukup tekan tombol AI di bagian bawah layar untuk berpindah model:

  • Ishimi 大: Karakter AI utama dengan kepribadian tegas, pintar, dan system prompt khusus.
  • ChatGPT: Pertanyaan umum, menulis esai, atau bikin kode.
  • Claude AI: Percakapan panjang & merapikan teks.
  • DeepSeek & Qwen: Logika dan matematika.

Fitur unggulan: Setiap AI punya memori (history) sendiri-sendiri. Jadi obrolanmu dengan ChatGPT tidak akan tercampur saat kamu pindah ke Ishimi. Kamu juga bisa membuat banyak thread obrolan baru lewat sidebar kiri.

📥 2. Downloader Otomatis

Selain untuk mengobrol, aplikasi ini juga berfungsi sebagai "tukang download". Tersedia tombol cepat untuk TikTok, Instagram, dan YouTube. Cukup paste link video, dan aplikasi akan memanggil API untuk mengambil video aslinya. Video langsung muncul dan bisa diputar di dalam chat — tanpa perlu membuka aplikasi lain.

🎬 3. AI Video Enhancer (HD Video)

Punya video buram atau kualitas rendah? Fitur HD Video memungkinkan kamu:

  • Memasukkan link video atau mengunggah dari galeri.
  • Memilih target resolusi: 720p / 1080p / 4K.
  • Aplikasi memanggil API untuk meningkatkan kualitas video.
  • Kamu menerima link hasil video yang sudah di-upgrade.

📎 4. Dukungan Lampiran File

Dalam mode chat AI, kamu bisa mengunggah gambar atau PDF melalui tombol klip kertas (📎) — mendukung percakapan berbasis dokumen dan visual.

🎨 5. Desain Neo-Brutalism + Video Background

Dari sisi tampilan, aplikasi ini mengusung gaya Neo-Brutalism (kotak tebal, bayangan keras, font bold). Kombinasi warna tema gelap (ungu/hitam) dipadukan dengan video background bergerak di belakangnya. Dilengkapi sistem login simpel dan animasi splash screen.

Ringkasan: Satu aplikasi untuk chat multi-AI, download video sosial media, upgrade kualitas video ke HD/4K, dan upload file — semuanya dibungkus dalam desain Neo-Brutalism yang futuristik. 🎯
